# GB-LAMP

[English](README.md) | [Українська](README.ua.md)

Проєкт для швидкого запуску LAMP-стеку (Linux, Apache, MySQL, PHP) з використанням Docker Compose. Дозволяє миттєво розгорнути локальне середовище розробки з вибором версії PHP безпосередньо в корені проєкту (підтримується OpenCart та інші CMS/сайти).

## Можливості

- **Миттєве підключення до будь-якого проєкту**: встановлення середовища однією командою через `curl | bash`
- **Вибір версії PHP**: підтримка PHP 7.4, 8.0 та 8.2
- **Робота в корені проєкту**: сайт обслуговується безпосередньо з кореня репозиторію
- **Автоматична ініціалізація**: копіювання необхідних конфігурацій та створення `.env`
- **Керування базою даних**: автоматичний імпорт SQL-дампів з попереднім очищенням таблиць
- **Керування контейнерами**: команди запуску, зупинки, очищення та налаштування прав
- **Гнучке налаштування**: зручна конфігурація через файл `.env`
- **Безпечний запуск**: контейнери не запускаються автоматично при перезавантаженні системи (`restart: "no"`)

## Вимоги

- Docker та Docker Compose
- Make (для виконання команд Makefile)
- Bash shell

## Встановлення та запуск

### 1. Підключення до будь-якого існуючого проєкту (рекомендовано)

Перейдіть у кореневу директорію вашого проєкту (наприклад, з OpenCart або іншим сайтом) та виконайте команду:

```bash
curl -sSL https://raw.githubusercontent.com/GregoryBiter/gb-lamp/main/lamp.sh | bash
```

Скрипт автоматично:
- Завантажить компоненти GB-LAMP (`.docker/`, `Makefile`, `.env.example`, `.vscode/`)
- Додасть необхідні правила до `.gitignore` вашого проєкту (служебні файли Docker, кэш та логи OpenCart)
- Запустить інтерактивну ініціалізацію (`init.sh`) для вибору версії PHP та створення `.env`

---

### 2. Запуск всередині клонованого репозиторію gb-lamp

Якщо ви працюєте безпосередньо в цьому репозиторії:

1. **Швидкий старт**:
   ```bash
   make start
   ```
   *Якщо `docker-compose.yml` або `.env` ще не створені, команда автоматично викличе майстер ініціалізації.*

2. **Ручна ініціалізація**:
   ```bash
   make init
   ```
   Оберіть версію PHP (1 — PHP 7.4, 2 — PHP 8.0, 3 — PHP 8.2). Буде згенеровано `docker-compose.yml`, запропоновано створити `.env` та виконати імпорт бази даних.

3. **Імпорт бази даних**:
   ```bash
   make db-import
   ```
   Скрипт автоматично знайде файл `.sql` у корені проєкту та імпортує його в MariaDB з попереднім очищенням існуючих таблиць.

## Конфігурація

### Файл .env

Після ініціалізації відредагуйте файл `.env` під ваші потреби:

```bash
VHOST_SERVER_NAME=myproject.local
MYSQL_ROOT_PASSWORD=root
MYSQL_DATABASE=myproject
MYSQL_USER=dev_user
MYSQL_PASSWORD=dev_password
```

### Додавання локального домену в hosts

Якщо `VHOST_SERVER_NAME` відрізняється від `localhost`, додайте запис до `/etc/hosts`:

```bash
127.0.0.1 myproject.local
```

Команда `make start` перевіряє та пропонує додати запис автоматично.

## Доступ до сервісів

Після запуску доступні такі сервіси:

- **Веб-сервер**: [http://localhost](http://localhost) (або ваш `VHOST_SERVER_NAME`)
- **phpMyAdmin**: [http://localhost:8080](http://localhost:8080)
- **База даних MariaDB**: `localhost:3306`

---

## Команди Makefile

- `make help`: Показати довідку за доступними командами
- `make init`: Ініціалізувати середовище з вибором PHP та створенням конфігурацій
- `make start`: Перевірити конфігурацію, додати хост та запустити Docker Compose
- `make db-import`: Імпортувати SQL-дамп з кореня проєкту в базу даних
- `make clean`: Зупинити контейнери, видалити томи та очистити неактивні образи
- `make fix-permissions`: Налаштувати права доступу до файлів та папок проєкту

## Структура проєкту

```bash
.
├── .docker/
│   ├── configs/          # Конфігурації сервісів (Apache, MySQL, PHP)
│   ├── example-config/   # Шаблони конфігурацій CMS (OpenCart)
│   ├── scripts/          # Скрипти ініціалізації та запуску
│   └── templates/        # Шаблони docker-compose.yml для версій PHP
├── docker-compose.yml    # Активна конфігурація Docker Compose (створюється при init)
├── .env                  # Змінні оточення (створюється з .env.example)
├── .env.example          # Приклад файлу змінних оточення
├── Makefile              # Команди для керування проєктом
└── lamp.sh               # Скрипт встановлення LAMP у будь-який проєкт
# Файли сайту / OpenCart розміщуються безпосередньо в корені проєкту
```

## Усунення несправностей

- **Відсутні файли конфігурації**: Виконайте `make init` або `make start`.
- **Проблеми з правами доступу**: Запустіть `make fix-permissions`.
- **Контейнери не запускаються або помилка портів**: Перевірте логи з `docker compose logs` та переконайтеся, що порти `80`, `3306` або `8080` не зайняті іншими службами.
- **Помилка підключення до БД**: Перевірте параметри підключення у файлі `.env`.
